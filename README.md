# 🌸 ASCII Lily Bouquet

A bouquet of lilies grows and blooms, drawn entirely with ASCII characters in the browser.

**Live demo:** https://foiz-imtiaz.github.io/lily-bouquet/

## How it works
1. Flowers are drawn on a hidden canvas.
2. Every pixel is read and mapped to a character by brightness.
3. Characters are drawn on screen in the pixel's color.

## Controls
- Tap or click to replay
- Drag to blow the wind

Built with plain HTML, CSS and JavaScript. No libraries.
